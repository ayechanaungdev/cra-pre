EXECUTIVE SUMMARY,,,,,,,,,,,,,,
"The Car Rental Management System is a secure mobile platform that connects car owners with renters. The system targets into 3 types of users to manage operations smoothly:
Admins: Oversee the entire system, verify new cars, and manage user access (Blacklist/Whitelist).
Car Owners: Manage their own fleet of vehicles and assign professional drivers from their private pool.
Renters (Users): Enjoy an easy-to-use interface for browsing, booking, and real-time chatting.

Built with React Native and Supabase, this solution provides a fast, reliable, and secure experience for all users with real-time data updates.",,,,,,,,,,,,,,
